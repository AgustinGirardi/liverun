# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

NOTE: el proyecto se bajó de SDK 56 a SDK 54 (2026-06-11) porque Expo Go del
App Store de iOS solo soporta SDK 54 y el usuario prueba en iPhone. Cuando
Expo Go SDK 56 llegue al App Store, se puede re-upgradear con
`npx expo install expo@^56.0.0` + `npx expo install --fix` (y revisar la API
de NativeTabs, que cambió entre versiones).
